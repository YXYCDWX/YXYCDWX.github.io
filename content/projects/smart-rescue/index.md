## 任务概述

参加中国大学生工程实践与创新能力大赛「智能+」工程创新赛道智能救援赛项。本项目的视觉子系统需同时完成目标检测与区域归属判定两级任务：识别赛场内的待救援目标，并判定目标是否处于规定安全区。

## 技术方案

| 模块 | 实现 |
|------|------|
| 目标检测 | YOLO 模型，基于赛场数据集与角度分析数据集训练 |
| 安全区判定 | OpenCV 交互式选点构建多边形安全区，像素级采样保存基准色（BGR CSV） |
| 结果输出 | 批量推理输出标注图与检测结果文本 |
| 数据体系 | 赛场数据集 + 角度分析数据集分离管理，训练/验证独立划分 |

## 工程要点

- **两级判定结构**：检测模型回答"是什么"，OpenCV 多边形区域回答"在哪里"，两步解耦便于分别调试
- **安全区标定工具化**：交互式选点采集安全区多边形顶点与基准像素色，赛场更换场地后可快速重新标定
- **批量验证**：对赛场数据集全量回放推理，输出标注图逐一核查，避免仅凭指标数字误判模型实际表现
