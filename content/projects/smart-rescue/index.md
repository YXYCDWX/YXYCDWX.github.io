## 任务概述

参加中国大学生工程实践与创新能力大赛「智能+」工程创新赛道智能救援赛项。板端摄像头识别赛场内的待救援目标，解算目标相对机器人的距离与角度经串口发给电控；同时用 LAB 颜色阈值实时检测紫色安全区，处于安全区内的目标自动屏蔽，避免重复救援。

## 模型训练

| 项 | 配置（代码原值） |
|------|------|
| 数据集 | datasets/rescue/data.yaml，4 类：绿色正方形、蓝色正方形、黑色三角形、橙色长方形 |
| 训练 | epochs=150, imgsz=640, batch=16, patience=40, seed=42, workers=0（Windows 单进程防死锁） |
| 增强 | degrees=20, translate=0.2, scale=0.7, shear=15, perspective=0.002, fliplr=0.5, flipud=0, mosaic=1.0, close_mosaic=15, mixup=0.15 |

增强策略考虑了赛场观察角度的多变性：±20° 旋转、0.7 倍尺度抖动与 15° 剪切覆盖侧向观察的形变，mosaic 与 mixup 提升小目标与遮挡场景鲁棒性，最后 15 轮关闭 mosaic 让模型回归真实分布。

## 板端推理与目标解算

YOLO 模型 640×640 输入，置信度 0.6，NMS IoU 0.2，最大 50 框；显示 800×480（st7701 屏），推理帧率 30fps。

**距离与角度解算**（以画面底部中心为参考点）：

```
角度 = -degrees(atan2(cx - ref_cx, ref_y - cy))
距离 = sqrt((bx - ref_cx)² + (ref_y - by)²) / 10
```

**目标选择状态机**：

{{< mermaid >}}
flowchart TD
    A[上电 Fsales 待命] -->|收到 101| B[进入 ready 清空锁定目标]
    B --> C{选择目标}
    C -->|Fsales 状态| D[只选绿色正方形]
    C -->|ready 状态| E[优先级 绿色正方形 > 橙色长方形 > 黑色三角形]
    D & E --> F[同类多个时随机选一<br>锁定 track_target]
    F -->|收到 100| G{锁定目标仍在?}
    G -->|是| H[输出 编号,距离,角度]
    G -->|否| I[按当前优先级重选]
    H --> J[格式 %d,%.1f,%.1f 无目标回 0]
{{< /mermaid >}}

收到 `101` 触发一次任务重置；收到 `100` 时若锁定目标仍有效则直接回发，避免输出抖动；同类多目标随机选择防止反复横跳。

## 紫色安全区屏蔽

在 YOLO 通道之外增开一路检测通道，三路并行互不阻塞：

| 通道 | 格式与用途 |
|------|------|
| CHN0 | YUV420SP，显示 |
| CHN1 | RGB565 320×320，紫色安全区检测 |
| CHN2 | RGB888 640×640，YOLO 推理 |

- 紫色 LAB 阈值：(L 25~50, A 7~35, B -42~-16)，配合形态学补全
- 区域约束：像素数 ≥80，合并边距 25，最小尺寸 30
- **判定点取检测框下边中点**（目标底部接地位置），映射到 320×320 安全区图上做命中判断，而非用框中心——目标下半身在区内才算真正进入安全区
- 安全区内目标画灰色框并标注"已屏蔽"，不进入目标字典，不参与选择

## 标定与验证工具

- opencv安全区算法.py：交互式选点采集安全区多边形顶点，逐点保存 BGR 基准色到 CSV，换场地后快速重标定
- scan_color.py / plot_on_image.py：颜色扫描与结果可视化，配合 _color_scan 报告核查颜色阈值覆盖范围
- 赛场数据集全量回放推理输出标注图，逐一人工核查，避免仅凭指标数字误判模型实际表现
