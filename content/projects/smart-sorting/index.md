## 任务概述

参加中国大学生工程实践与创新能力大赛「智能+」工程创新赛道智能分拣赛项。比赛要求将形状相同且颜色相同的货物分拣到对应储物盒，一次只能处理一件托盘中的货物。本系统实时识别 X 轴上五个空间位置的物体类别，将识别结果经串口发送给下位机执行分拣动作。核心难点在于：单帧识别存在突变噪声，而串口输出一旦错误即造成执行机构误动作。

## 技术方案

| 模块 | 实现 |
|------|------|
| 检测模型 | YOLO 目标检测，灰度处理降低颜色与光线干扰 |
| 检测管线 | 差分阈值、面积阈值、NMS、峰合并 |
| 空间定位 | 圆形 ROI + X 轴标定，像素坐标映射到物理空间位置 |
| 输出决策 | 时间 / X 轴空间位置 / 类别置信度三维表格的判断函数 |
| 双端架构 | 板端推理 + PC 端调试代码，串口通讯 |

## 核心设计：多帧置信度决策

直接输出单帧识别结果不可靠。本方案将串口输出从"识别即输出"改为"决策后输出"：

1. **置信度对比纠错**：X 轴五个空间位置中出现两个相同类别时，比较两者置信度，置信度长期处于第二位的类别判定为误检，以此逐级排除。
2. **缺失值补全**：根据 X 轴上已识别结果的一般间隔距离推断潜在缺失位置，模型漏检一个时自动补全该位置的位置与类别。
3. **动态置信度阈值**：模型效果较好但置信度偏低时，固定阈值要么漏检要么误报；在类别数量已知的任务约束下动态调整阈值。

## 工程经验

- 摄像头定位是重中之重：固定性与可调试性需同时保证，本赛项曾因螺丝拧紧程度差异导致摄像头偏移、识别区域漂移
- 数据集质量优于数量：需同时保证类别均衡与"情况均衡"（正对 / 左侧 / 右侧视角），理想数据集在真实赛场泛化性不足
- 与任务弱相关的数据增强也建议少量随机加入，防止未知场地泛化性崩塌
