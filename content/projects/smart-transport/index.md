## 任务概述

智能搬运任务中，机器人需依据场地环靶的颜色与位置信息完成抓取与搬运决策。本项目的视觉子系统要求在保证实时性的前提下稳定输出环靶颜色类别与中心位置。

## 技术方案

| 模块 | 实现 |
|------|------|
| 颜色检测 | HSV 颜色阈值法，阈值由现场采样标定（颜色采样 CSV → 阈值 CSV） |
| 形状识别 | 霍夫圆形识别，定位环靶中心 |
| 分析工具链 | 图片检测、视频逐帧检测、批量抽帧三套工具独立封装 |
| 结果验证 | 检测结果标注图与阈值判定结果交叉比对 |

## 工程要点

- **阈值标定流程化**：现场光照不可控，采用"采样 → 建阈值表 → 批量回放验证"的闭环流程，替代手工试错
- **工具拆分**：颜色检测、圆形识别、批量抽帧各自独立成工具脚本，赛场现场按需组合调用，降低调试成本
- **传统视觉优先**：该任务目标颜色特征明确、类别有限，纯 OpenCV 方案即可满足实时性与精度要求，无需深度模型
